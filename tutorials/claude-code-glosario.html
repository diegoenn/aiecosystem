Los términos, comandos y conceptos que uso a diario trabajando con Claude Code, en una sola página para tener al lado mientras construyo.

Claude Code trae un vocabulario propio — comandos con slash, modos de permisos, tipos de memoria, formas de orquestar agentes — que al principio se siente denso. Esta página junta las definiciones cortas que uso yo mismo como chuleta, agrupadas por tema en vez de alfabéticamente, para que tengan sentido en el orden en que normalmente las vas necesitando.

1Comandos rápidos

Los comandos con slash que se escriben directamente en el chat de Claude Code, sin salir de la sesión.

ComandoQué hace
/modelCambia la familia de modelo con la que trabaja la sesión actual.
/usageMuestra cuánto uso llevas consumido en el bloque de horas y en la semana.
/contextIndica qué porcentaje de la ventana de contexto está ocupado en este momento.
/compactResume la conversación para liberar espacio de contexto (hoy también ocurre solo).
/clearBorra la conversación actual y arranca una sesión en blanco.
/rewindDeshace cambios recientes en la conversación o en el código — el "Ctrl+Z" de la sesión.
/resumeRetoma una sesión anterior con todo su historial y contexto.
/memoryMuestra y permite editar lo que Claude recuerda de ti entre sesiones.
/agentsLista los subagentes disponibles y permite crear nuevos.
/permissionsConfigura qué acciones puede ejecutar Claude sin pedirte confirmación.
Shift + TabCambia el modo de permisos al vuelo, sin interrumpir lo que estás haciendo.

2El ecosistema Claude

Claude Code es una pieza de un conjunto más grande de productos de Anthropic; conviene distinguirlos.

TérminoQué es
AnthropicLa empresa que desarrolla los modelos Claude.
ClaudeLa familia de modelos de lenguaje de Anthropic.
Claude CodeEl agente de esta guía: la interfaz pensada para construir y ejecutar tareas de software de principio a fin, no solo conversar.
ModeloEl motor que procesa cada solicitud. Se elige por familia (rendimiento/costo), no por la versión puntual.
Opus / Sonnet / HaikuLas familias de modelos según el balance entre capacidad y velocidad: Opus para razonamiento pesado, Sonnet como opción rápida y capaz para el día a día, Haiku para tareas simples y en volumen.
Plan de suscripciónEl nivel de cuenta (Free, Pro, Max) que determina cuánto uso tienes disponible por sesión y por semana.

3Instalación e interfaz

TérminoQué es
TerminalLa forma original de usar Claude Code: una ventana de línea de comandos.
App de escritorioLa interfaz gráfica que integra chat, archivos, navegador y terminal sin instalar nada adicional.
IDEUn entorno de desarrollo tradicional (VS Code, JetBrains, etc.) donde Claude Code también puede integrarse como extensión.
SesiónUna conversación de trabajo con contexto propio. Regla práctica: tarea nueva, sesión nueva.
ProyectoLa carpeta sobre la que trabaja Claude Code; por defecto solo ve lo que hay dentro de ella.
PromptLa instrucción que le das a Claude — funciona mejor entre más contexto y claridad le das, como si le hablaras a una persona nueva en el equipo.
Nivel de esfuerzoCuánto "piensa" el modelo antes de responder: bajo es más rápido y barato, alto suele dar mejores resultados en tareas complejas a mayor costo.

4Tokens, contexto y límites

TérminoQué es
TokenLa unidad mínima de texto que procesa el modelo. Todo lo que entra y sale de la conversación consume tokens.
Ventana de contextoTodo lo que Claude "tiene presente" en la sesión actual — como el espacio disponible sobre un escritorio de trabajo.
Context rotLa degradación de calidad que ocurre cuando una conversación se vuelve demasiado larga. La solución habitual es empezar una sesión nueva.
CompactarResumir lo conversado hasta el momento para liberar espacio de contexto sin perder lo esencial.
Límite de sesión / semanalLas cuotas de uso de tu plan, por bloque de horas y por semana — se consultan con /usage, no se estiman a ojo.

5Modos de permisos y control

Cuánta autonomía le das a Claude Code para actuar sin preguntarte antes.

ModoQué implica
Manual (default)Pide permiso antes de cada acción relevante. El punto de partida recomendado mientras aprendes el flujo.
Accept EditsAcepta automáticamente las ediciones de archivos, sin preguntar una por una — más velocidad, menos fricción.
Plan ModeClaude piensa y propone un plan de acción sin tocar nada todavía, ideal para revisar el enfoque antes de gastar tiempo o cuota.
BypassAutonomía total, sin confirmaciones. Solo recomendable en entornos aislados y controlados.
CheckpointUna especie de "foto" automática del estado antes de cada cambio, que es lo que hace posible deshacer con /rewind.
⚠️
Cuándo usar cada uno

Manual para tareas nuevas o sensibles, Accept Edits para iterar rápido en algo que ya conoces, Plan Mode antes de tareas grandes o ambiguas, y Bypass solo en un sandbox donde un error no cuesta nada.

6CLAUDE.md, memoria y archivos

TérminoQué es
CLAUDE.mdEl archivo de instrucciones del proyecto: quién eres, tus reglas, tu tono. Se carga automáticamente en cada sesión — conviene mantenerlo corto y concreto.
Nivel global vs. localGlobal vive en tu carpeta de usuario y aplica a todos tus proyectos; local vive dentro de un proyecto y aplica solo ahí. Regla práctica: lo que siempre haces igual va en global, lo específico del proyecto va en local.
Memoria automáticaLo que Claude anota por su cuenta sobre ti y tu forma de trabajar entre sesiones, para no repetir el mismo contexto cada vez.

7Skills

TérminoQué es
SkillUna forma de hacer algo convertida en procedimiento reutilizable, que se invoca luego con /nombre-del-skill.
Skill global vs. localIgual que con la memoria: disponible en todos tus proyectos, o solo en uno.
MarketplaceEl catálogo de skills y plugins creados por otras personas, listos para instalar con un comando.
✅
El truco que más uso

Cuando una sesión larga finalmente da con el resultado que quería, antes de cerrarla le pido a Claude que convierta ese proceso en un skill — así la próxima vez no repito el mismo tanteo desde cero.

8MCP y conectores

TérminoQué es
MCPModel Context Protocol: el estándar que permite a Claude hablar con herramientas y servicios externos de forma consistente.
APILa puerta técnica que expone un servicio para integrarse con él. Un servidor MCP es básicamente esa puerta ya adaptada para que un agente la use.
ConectorUn servidor MCP ya configurado y listo para activar (Gmail, Notion, GitHub, Vercel, y cientos más).
OAuthEl flujo de autorización que conecta tu cuenta con un par de clics, sin tener que copiar ni pegar claves manualmente.

9Subagentes y orquestación

TérminoQué es
SubagenteUna instancia con contexto propio (mente "fresca") que se encarga de una parte específica del problema.
Secuencial vs. paraleloSubagentes que trabajan uno tras otro, o varios al mismo tiempo sobre partes distintas de la misma tarea.
OrquestarCoordinar ese equipo de subagentes en vez de ejecutar cada paso directamente.
Maker y checkerUn patrón donde un agente hace el trabajo y otro, independiente, lo revisa antes de dártelo — reduce el riesgo de que un error pase desapercibido.

10Loops y goals

TérminoQué es
LoopUna tarea que se repite a intervalos definidos (cada hora, cada mañana, etc.).
GoalUna tarea que se ejecuta hasta cumplir una condición verificable, y ahí se detiene por sí sola.
Meta verificableUna condición que se puede comprobar objetivamente (sin opinión humana de por medio) — sin esto, un loop puede quedarse corriendo sin sentido y consumiendo cuota.

11Automatización 24/7

TérminoQué es
RoutineClaude Code ejecutándose en la nube, sin depender de que tu computador esté encendido.
TriggerEl evento que dispara una automatización.
Event-triggeredSe dispara cuando ocurre algo puntual (por ejemplo, alguien completa un formulario).
Time-triggeredSe dispara según un horario fijo (por ejemplo, todos los días a las 7am).
WebhookLa URL que recibe el aviso de que algo pasó en otro sistema, y que puede usarse para disparar una automatización.
Human in the loopUn punto de control donde nada se envía o publica sin que una persona lo apruebe primero.
n8nUna plataforma de automatización externa que puede conectarse a Claude Code vía MCP para tareas que necesitan correr de forma continua e independiente de tu suscripción.

12Navegador e investigación

TérminoQué es
Navegador nativoClaude operando un navegador real — viendo la página tal como la ves tú, no solo leyendo su código.
ScrapingExtraer información de una página que no ofrece una API ni un conector MCP oficial.

13Segundo cerebro

Cómo usar Claude Code para construir y consultar una base de conocimiento propia.

TérminoQué es
Segundo cerebroUna colección de notas conectadas entre sí que Claude puede construir, mantener y consultar como referencia.
ObsidianUn visor gratuito para navegar esas notas y el grafo de conexiones entre ellas.
WikilinkEl enlace [[así]] entre notas que arma la red de conexiones.
RAGRetrieval-Augmented Generation: búsqueda por similitud sobre bases de datos grandes. Útil para volúmenes masivos de documentos; para colecciones más chicas, una wiki de notas suele ser más simple y igual de efectiva.
