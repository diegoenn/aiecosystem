Estado del proyecto

Qué hay hoy y qué sigue

El ecosistema se alimenta de forma incremental. Este es el estado actual.

  • Mapa del SDLC (10 etapas) — herramientas, alternativas y el "por qué" de cada categoría.
  • Tutorial de Git & GitHub — guía de referencia diaria con buenas prácticas de seguridad.
  • Catálogo inicial de AI Tools & Models — modelos, coding agents, prototipado y observabilidad.
  • Comparativas de modelos (Claude, GPT, Gemini) para tareas de desarrollo — en progreso.
  • Tutoriales de agentes de código (Claude Code, Cursor, Copilot) — próximamente.
